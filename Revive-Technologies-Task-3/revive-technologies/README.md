# Bee's Events & Décor

**Integrated Event Decorating and Freelance Management System**, built by Revive Technologies.

Bee's Events & Décor is an event décor business based in Hammanskraal and serving clients across South Africa, with more than 15 years of experience and a network of vetted freelance event professionals. This web application is the company's public website together with three secure portals for clients, freelancers and the admin team.

## Public website

The home page presents the business under the tagline *Where Every Event Becomes Extraordinary*:

- **Services**: wedding décor, baby showers and reveals, kids' and adult parties, and corporate and gala events.
- **Our Story**: the company's background and a link to work with the team.
- **Portfolio gallery**: "Our Signature Work", filterable by Kids Party, Baby Shower, Gender Reveal, Traditional, Wedding and Adult Party.
- **Testimonials**: feedback from past clients.
- **Join Our Team**: floral designers, balloon artists, stylists and setup coordinators can apply to the freelancer network.
- **Contact**: phone, email, location and an enquiry form that creates a client account. Sign In and Register open as a pop-up over the home page.

## Client portal

- **Portfolio**: browse décor packages (Floral Arch Wedding, Zulu and Venda Traditional Weddings, Custom Heritage Ceremony, Lobola & Engagement Celebration, Kids Birthday Wonderland, Baby Shower & Gender Reveal, Adult Milestone Birthday, Balloon Luxury Install, Grand Ballroom Gala), customise one and request a quote.
- **Submit Design**: describe a custom décor vision for the design team.
- **Invitation Cards**: request custom invitations, follow a progress bar and download the finished cards once complete.
- **Request Quote / My Quotations**: view itemised quotations and download the PDF once approved. Approved quotations require a deposit within 72 hours.
- **Messages, Notifications and My Profile**: chat with the team, receive in-app updates and manage account details and profile photo.

## Freelancer portal

- **Dashboard**: earnings, jobs completed, upcoming jobs and rating.
- **Available Jobs**: browse confirmed events that still need a freelancer and apply; the admin accepts or rejects applications.
- **My Jobs**: track assigned events and mark them as completed.
- **Earnings**: payout history and payment claims for completed jobs.
- **Messages, Notifications and My Profile.**

## Admin portal

- **Dashboard**: revenue, bookings, low-stock alerts and an upcoming tasks list (tasks are added automatically when a quotation is approved).
- **Quotations**: build, edit, approve or reject itemised quotations and download them as PDFs.
- **Invitation Cards**: approve or reject requests, update progress, message the client and upload finished cards.
- **Inventory**: add, restock and remove décor items, with low-stock warnings.
- **Calendar**: month view of confirmed events.
- **Freelancers**: manage accounts, review job applications and approve payment claims.
- **Messages, Notifications and My Profile.**

## Technology

PHP 8 and MySQL (PDO with prepared statements), plain HTML, CSS and JavaScript. Passwords are hashed with `password_hash()`. Quotation PDFs are generated by a built-in PDF writer, so no external libraries are required. A small token-based JSON API (`api/`) serves the mobile app for login, bookings, quotations, messages and inventory.

## Project structure

```
index.php            Public home page
auth/                Sign in, register, forgot password, sign out
client/              Client portal
freelancer/          Freelancer portal
admin/               Admin portal
api/                 JSON API for the mobile app
includes/            Shared layout, helpers, role checks, PDF writer, package catalogue
config/              Database connection (database.local.php overrides it on a host)
assets/              CSS, JavaScript and images
uploads/             Profile photos, freelancer portfolios and finished invitation cards
database/            Schema, sample data and migrations
```

## Database

The schema in `database/revive_technologies.sql` (or `revive_technologies_hosting.sql` for hosted databases) contains these tables: `users`, `freelancers`, `inventory`, `bookings`, `quotations`, `quotation_items`, `payments`, `receipts`, `messages`, `notifications`, `tasks`, `invitation_requests` and `job_applications`, plus sample admin, client and freelancer accounts. The files prefixed `migration_` and `api_tokens.sql` add features to an existing database.

## Local setup

The site runs on XAMPP (Apache, PHP, MySQL). Place the project in `htdocs`, import `database/revive_technologies.sql` through phpMyAdmin and open `http://localhost/revive-technologies/`. The default settings in `config/database.php` match a standard XAMPP install. The `uploads/` folders must be writable by the web server.

## Notes

- Deposit payments are not connected to a payment gateway; the deposit page shows the amount due and next steps.
- Notifications are in-app only; no email or SMS is sent.
- Packages are defined in `includes/packages_data.php`.
