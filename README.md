# Revive Technologies Task 3

Official PHP website and mobile application for **Bee's Events & Decor**.

This repository holds two software solutions developed for Bee's Events & Decor as part of the Revive Technologies Task 3 assessment.

## Projects Included

| Project | Description |
|---|---|
| **Bee's Events & Decor Website** (`revive-technologies/`) | A dynamic company website built with PHP and MySQL. It showcases event services and décor portfolios, and includes secure portals for clients, freelancers and the admin team to handle bookings, quotations, invitations and enquiries. |
| **Decorra App** (`Decorra/`) | A companion mobile application (Flutter) for Bee's Events & Decor that streamlines client engagement and event management. |
